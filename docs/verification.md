# 0.3.0 验证记录

验证环境：Windows、Node.js 24、Microsoft Edge。全部使用独立数据目录与合成输入。

## 自动化测试

22 / 22 通过。覆盖空库、兼容迁移、课程结构、目录与知识点规划、时间计划和路线一致性、1至3节批次限制、版本冲突、前置依赖、知识点覆盖、详细教材检查、发布失败回滚、已有教材与笔记保留、每节位置与百分比、完成状态、重启持久化、电子书渲染、CLI、导入导出与本机来源校验。

删除测试覆盖：第一步不改变数据、缺失凭据、课程名称不匹配、跨课程误用、五分钟过期、课程已改变、重复提交、恢复备份后凭据失效。确认删除后清除该课程的笔记、草稿、进度与阅读位置，其他课程数据保留；迟到的自动保存不能恢复已删除课程。

## 浏览器检查

- 图标在页面品牌区和浏览器资源中正确加载。
- 两步删除界面可取消，Esc 可退出；完整名称匹配前删除按钮禁用。
- 确认删除后回到课程库，其他课程仍存在。
- 已打开的另一标签页可感知删除、丢弃该课程过期草稿并回到课程库。
- 立即关闭阅读标签页时，退出保存仍生效。
- 390 像素移动布局中，空课程库与删除弹窗无横向溢出。
- 未发现 JavaScript 运行错误。
- 分批课程显示总章数、总节数、已生成节数，待生成小节不能标为已完成。
- 当前课程打开期间追加教材，页面能够刷新为可读内容。
- 通过课程目录切换小节后，各自的阅读位置、笔记和实践草稿可恢复；刷新页面继续停留在保存的位置。
- 课程概览的继续学习入口指向最近阅读小节，阅读百分比与手动完成状态分别处理。
- 思维导图包含章节、小节和知识点；电子书明确标识待生成部分，并可下载当前版本快照。
- 恢复较早规划后，已打开标签页会丢弃不再可用小节的过期待写入草稿，并正确展示待生成状态。

预览图片仅使用独立库中的合成结构数据。浏览器检查不替代不同设备、浏览器及真实教材的使用验证。

## 分享包检查

打包脚本使用文件白名单，并逐项校验 ZIP 内容和 SHA-256。空框架首次启动不含课程。程序测试结果不构成对生成教材内容的教学认证。

电子书格式为离线 HTML；EPUB 和 PPT 需另行制作。
