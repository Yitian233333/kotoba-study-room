# 0.2.1 验证记录

验证环境：Windows、Node.js 24、Microsoft Edge。全部使用独立数据目录与合成输入。

## 自动化测试

13 / 13 通过。覆盖空库、旧版迁移与历史字段清理、课程完整性、计划和路线图一致性、乱序保存、批次回滚、重启持久化、电子书安全渲染、命令行完整发布、导入导出与本机来源校验。

新增删除测试覆盖：第一步不改变数据、缺失凭据、课程名称不匹配、跨课程误用、五分钟过期、课程已改变、重复提交、恢复备份后凭据失效。确认删除后清除该课程的笔记、草稿、进度与阅读位置，其他课程数据保留；迟到的自动保存不能恢复已删除课程。

## 浏览器检查

- 图标在页面品牌区和浏览器资源中正确加载。
- 两步删除界面可取消，Esc 可退出；完整名称匹配前删除按钮禁用。
- 确认删除后回到课程库，其他课程仍存在。
- 已打开的另一标签页可感知删除、丢弃该课程过期草稿并回到课程库。
- 立即关闭阅读标签页时，退出保存仍生效。
- 390 像素移动布局中，空课程库与删除弹窗无横向溢出。
- 未发现 JavaScript 运行错误。

## 分享包检查

打包脚本使用文件白名单，并逐项校验 ZIP 内容和 SHA-256。空框架首次启动不含课程。程序测试结果不构成对生成教材内容的教学认证。

电子书格式为离线 HTML；没有默认 EPUB、PPT、真人录音或专业发音评分。
