# 共享与隐私范围

公开框架从空课程库开始。课程规划、教材批次、访谈、学习目标、笔记、当前草稿、每节阅读百分比与停留位置、完成时间、数据库快照和本机日志均属于运行时数据，默认写入 data/，不在框架包内。

框架不包含账户凭据、固定 API 密钥、个人姓名、联系方式或特定电脑的绝对路径。路径由程序在运行时相对项目目录计算；桌面快捷方式在使用者自己的电脑上生成，快捷方式文件不参与打包。

程序只监听本机回环地址，不含遥测、广告或云同步。网页加载的脚本、样式和图标均来自本地服务。只有主动打开参考链接、使用浏览器或在 Codex 中生成课程时，才涉及相应外部服务及其账户。

共享前应同时检查：

- 使用文件白名单打包，只包含源代码、流程文档、图标和合成测试输入。
- 排除整个 data/、环境配置、日志、个人素材、工作区历史和 Git 元数据。
- 检查文档、截图、文件名、图片元数据和提交作者信息，不只检查代码。
- 不把含课程的“课程库备份”当作空框架分享。

删除课程仅作用于当前课程库，不会擦除已有导出文件、旧备份或数据库空闲页。框架不会把“删除”描述为安全擦除；分享时仍应始终排除整个 data/。

test/ 使用人工合成的通用结构数据。预览图由独立测试库生成，没有真实课程、个人笔记、登录信息或浏览器界面。
