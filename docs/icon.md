# 应用图标

图标使用内置 imagegen 生成，机械缩放为 PNG，并封装为包含 16、32、48、64、128、256 像素尺寸的 Windows ICO。页面使用 PNG，桌面快捷方式使用 public/app.ico。导出资源不含原图元数据。

设计：深蓝书本、米白纸页、琥珀色书签，适合安静的个人学习室。

生成提示词：

> Create a single polished desktop application icon for Kotoba, a calm personal learning library. A square icon filling the canvas, deep ink navy (#203554) rounded-square tile, ivory open book as the central bold geometric symbol, a small warm amber bookmark on the right page and a subtle ascending page/learning-path motif. Strong recognizable silhouette at 32 pixels. Crisp flat vector-like edges with very subtle dimensional paper layering, premium quiet editorial aesthetic, generous internal padding. No letters, no words, no Japanese characters, no external shadows, no mockup, no device, no border or extra background beyond the square icon. Centered, symmetrical balanced composition. Output one square app icon.
